## 免备案服务器“免”的是什么，代价又在哪

免的是 ICP 备案流程，代价是机房不在工信部管辖范围内，出问题时没有备案体系兜底。

香港机房不归大陆工信部管，域名解析到香港 IP 不强制 ICP 备案，买完就能上线——这基本是所有人选香港而不是大陆机房的核心原因。同一件事的另一面很少有人讲清楚：阿里云在分析免备案虚拟主机的缺点时提过，这类主机上的网站有被封的风险，因为工信部无法直接管理，实际处理手段是屏蔽 IP。
